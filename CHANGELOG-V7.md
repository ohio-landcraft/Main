# Ohio Landcraft Website — V7 Network Messaging Update

## What changed

- Added the new **one-stop rural property partner** message to the homepage hero.
- Added a major homepage section explaining the Ohio Landcraft partner-network model:
  - one point of contact,
  - broader practical knowledge,
  - right-sized crews and equipment,
  - Ohio Landcraft remaining involved in the customer experience.
- Updated the Landcraft process so “Craft” includes selecting the right people as well as equipment and materials.
- Added a new About-page section explaining how the network benefits the customer.
- Added three FAQs:
  - **Is Ohio Landcraft a general contractor?**
  - **Who will actually perform the work on my property?**
  - **Why use a partner network instead of one crew for everything?**
- Updated the existing “What makes Ohio Landcraft different?” FAQ to include the partner network and broader equipment choices.
- Added a compact network/point-of-contact section to all six core service pages so customers who land directly on a service page understand the model.
- Updated page meta descriptions and the Messaging Framework to support the new positioning.

## Messaging principle

The network should never read like a subcontracting disclaimer. The customer value is that Ohio Landcraft can start with the property goal and assemble a right-sized solution from a broader set of knowledge, equipment and specialty experience. The site is also transparent that some field work may be completed by trusted independent specialty partners.
