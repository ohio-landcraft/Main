# Ohio Landcraft Website — V8 Audience Paths

## What changed

- Added a compact **Who We Help** section to the homepage with only three concise cards.
- Added dedicated SEO/content pages for:
  - Cabin & vacation property owners
  - New rural property owners
  - Rural & acreage owners
- Cabin-owner page explicitly supports remote property evaluation and the message that customers can keep contractors they already trust.
- Added a **How do you use the property?** field to the starter evaluation form so future Survey123/CRM workflows can segment leads.
- Added Who We Help links to the footer rather than crowding the primary navigation.
- Added `sitemap.xml` and `robots.txt` so the new audience pages are easy for search engines to discover after deployment.
- No additional photography is required for V8; the new pages use the existing visual system and typographic page heroes.

## Homepage strategy

The homepage remains an orientation page. The new section is intentionally short and sends visitors to deeper audience-specific pages. This keeps scrolling reasonable while allowing those interior pages to carry more targeted search language and answer customer-specific questions.
